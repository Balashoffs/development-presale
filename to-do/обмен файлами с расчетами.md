###Задача
Реализовать функционал для обмена расчетами КП между пользователями калькулятора

###Алгоритм работы
1. Пользователь создал новый расчет, ввел данные по объекту
2. Открыл страницу для выбора ресурсов
3. Выбрал необходимое коли-во ресурсов
4. Как только будет добавдлен хоть один ресурс, на интерфейсе появляется кнока для загруки файла с данными по КП
5. Пользователь нажимает на эту кнопку и производит сохранение на локальном устройстве
6. При помощи любых средств обмена данными - почта, соц сеть и т.п. отправляет другому пользователю, в том числе и себе
7. Полученный файл можно загрузить в калькулятор в окне создания нового КП
8. После успешной загрузки файла, приложение открывает окно с полями для ввода данных о КП и подставляет данные из загруженного файла
9. Сохранить состояние расчетов можно на двух страницах 
   - на странице выбора ресурсов и разделов 
   - на странице подсчета маржинальности

###Этапы разработки
1. Добавить новую страницу "Список КП"
2. На это странице в будущем будет отображаться список ранее созданых и сохранненых КП (СиЗКП)
3. На странице должны быть слелующие кнопки:
   -  кнопка "создать КП" (СКП)
   - кнопка "загрузить КП" (ЗКП)
4. При нажатии на кнопку СКП - открывается страница для ввода данных по новому КП
5. При нажатии на кнопку ЗКП - отображается диалоговое окно с проводником для загрузки КП от другого пользователя
6. После успешной загрузки КП, отображается страница для ввода данных по новому КП с загруженными данными из файла
7. На страницах "Добавить разделы и ресурсы" (ДРиР) и "Расчет стоимости услуг" (РСУ) в "шапке" приложения добавить кнопку для выгрузки текущеного КП
8. Данная кнопка на странице ДРиР должна быть активна только в случае, если добавлен хоть один раздел и заполненные все необходимые поля

###Формат файла для обмена КП
1. Файл имеет расширение "presale"
2. Кодировка файла - UTF8
3. JSON -> Base64 -> XOR -> XOR -> Base65 - JSON

[ ] 5. Добавить страницу "СиЗКП",
